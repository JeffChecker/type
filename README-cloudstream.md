# ARD und ZDF für Cloudstream

Dieses Repository stellt einen kleinen Cloudstream Katalog für öffentlich rechtliche Mediatheken bereit.

Enthalten:

* ARD über den gepflegten Provider aus Bnyro/GermanProviders
* ZDF Mediathek über die öffentliche MediathekViewWeb Schnittstelle

Repository URL für Cloudstream:

https://raw.githubusercontent.com/JeffChecker/type/main/repo.json

Der ARD Provider bleibt beim Originalprojekt und wird beim Build nur in die Pluginliste eingebunden. Der ZDF Provider wird in diesem Repository gebaut.
